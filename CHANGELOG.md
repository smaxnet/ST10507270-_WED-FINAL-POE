# Changelog

All notable changes to the Kota Bite website are documented in this file.

The format is based on Keep a Changelog and follows a simple project release history for this static restaurant website.

## [1.0.0] - 2026-10-29

### Overview
This is the initial release of the Kota Bite website, a modern static business website designed for a South African kota food brand. The project includes multiple landing and service pages, a menu showcase, order workflow, quotation section, contact and enquiry page, and supporting styling and script logic.

### Added
- Initial website structure with multiple pages for core business functions
- `index.html` for the main landing page and brand introduction
- `menu.html` for product listing and concept pricing layout
- `order.html` for placing customer orders
- `quotation.html` for showing estimate and print-ready cost summary
- `contact.html` for customer communication and contact details
- `Enquiry.html` for enquiry-related information and navigation
- `check-out.html`, `Order-in.html`, and `Take-away.html` for order flow variants and checkout-related pages
- Shared website styling through `style.css`
- Client-side interactivity through `script.js`
- XML sitemap file to improve crawlability and search indexing
- Project README and release documentation
- Branded aesthetic using warm food-inspired colours such as cream, brown, gold, and orange

### Enhanced
- Created a premium, welcoming restaurant identity with strong brand messaging
- Added a custom navigation system across all pages for consistent user flow
- Included CTA buttons such as "Explore Our Menu", "Order Now", and "Start Your Order"
- Structured content around a restaurant theme including pricing, menu descriptions, and contact information
- Added consistent page titles and headings for a more polished website presentation
- Applied responsive CSS for better display on desktop and smaller screens
- Included product-style presentation for menu categories and specials

### Improved
- Standardized page content to match the Kota Bite brand and location information
- Unified page naming and internal navigation references for better usability
- Reworked sitemap entries to reflect all real pages in the project rather than placeholder content
- Improved the release documentation so the project history is easier to maintain

### Fixed
- Replaced placeholder sitemap values with actual website page references
- Corrected page structure to better represent the site architecture
- Resolved inconsistencies in page naming and menu navigation references
- Cleaned up the initial project documentation to better reflect the actual implementation

### Technical Notes
- The website is built as a static multi-page HTML/CSS/JavaScript project
- No backend or database is currently connected
- Forms are front-end focused and use JavaScript-based interactions and alert messages
- The site is intended for local viewing and deployment on hosting platforms such as Netlify or GitHub Pages

### Project Scope
This release focuses on creating a complete front-end prototype and brand presentation for Kota Bite. It supports customer browsing, menu viewing, ordering, quotation review, and contact submission experiences in a clean and modern layout.
