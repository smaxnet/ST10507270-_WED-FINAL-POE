KOTA BITE WEBSITE PROJECT
==========================

Project Overview
----------------
Kota Bite is a static restaurant and food-order website created for a South African kota brand. The project is designed to showcase the brand, present menu items and pricing, allow customers to place orders, generate quotations, and contact the business.

The website uses a warm, premium food branding style with colors such as cream, brown, gold, and orange, and is built using standard HTML, CSS, and JavaScript.


Website Purpose
---------------
This website is intended to:
- Introduce the Kota Bite brand and food concept
- Display the menu and promotional offerings
- Help customers place orders
- Show pricing estimates through a quotation page
- Allow customers to contact the business
- Support takeaway and checkout-style experiences


Pages Included
--------------
The project contains the following pages:

1. index.html
   - Main landing/home page
   - Brand introduction and hero section
   - Call-to-action links to menu and order pages

2. menu.html
   - Restaurant menu layout
   - Food and beverage pricing cards
   - Menu call-to-action button

3. order.html
   - Customer order page
   - Order related form fields and pricing logic

4. quotation.html
   - Price estimate page
   - Print option for quotation

5. contact.html
   - Contact information and contact form

6. Enquiry.html
   - Enquiry page for user questions/inquiries

7. check-out.html
   - Checkout and payment summary page

8. Order-in.html
   - Order-in variation page

9. Take-away.html
   - Takeaway/checkout flow page

10. sitemap.xml
    - XML sitemap used for search engine indexing

How to Run the Website
----------------------
To run the website locally:

1. Open the project folder in your browser or file explorer.
2. Double-click on index.html, or open it in a browser.
3. Navigate between pages using the website menu.

Alternatively, you can run a local web server from the project folder if you want a cleaner preview environment.

----------------
This is a static website and can be deployed to:
- Netlify
- GitHub Pages

Before deployment, update the actual domain URL inside sitemap.xml if needed.

- Some forms may be demo-style and use alert-based interaction.

- Image paths and file links should be checked if the project is moved to a new folder or server.
